Cloud-Native Employee
Management System

A full-stack production-grade deployment built to demonstrate Kubernetes orchestration, persistent storage, secrets management, and declarative IaC — not as a tutorial exercise, but as a real proof of SRE-level thinking.

What I actually built — and why it matters

Anyone can run a tutorial. This project exists to prove I can design and operate stateful, containerized applications with production-grade reliability requirements. The entire infrastructure is declared as code, secrets are never exposed in manifests, and storage is configured to survive pod failures — because production data doesn't care about your restart policy.

The application is a Flask/PostgreSQL full-stack system deployed on a MicroK8s cluster running on a Linux VPS. What distinguishes it from a demo: custom Storage Classes, validated PVC persistence across pod lifecycle tests, and GitHub as the single source of truth for the full infrastructure stack.
