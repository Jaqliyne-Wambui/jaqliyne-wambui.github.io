Project — Cloud-Native Employee Management System

Overview

A full-stack employee management system designed and deployed using modern DevOps practices. The system demonstrates containerization, orchestration, persistence, and secure configuration.

Architecture & Implementation

  • Built a multi-tier architecture consisting of frontend, backend (Flask), and PostgreSQL database
  • Containerized all services using Docker to ensure consistency across environments
  • Deployed application to a MicroK8s Kubernetes cluster hosted on a Linux VPS
  • Defined infrastructure using declarative YAML manifests (Infrastructure as Code)

Data & Persistence

  • Configured Persistent Volume Claims (PVCs) to ensure data survives pod restarts
  • Validated storage reliability through repeated pod lifecycle testing

Security & Configuration

  • Managed sensitive credentials using Kubernetes Secrets
  • Separated configuration from application code for better security practices

Service Exposure

  • Exposed application externally using NodePort services
  • Enabled controlled access to services running inside the cluster
